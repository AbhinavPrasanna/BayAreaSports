# Advanced game details

Each NBA/NFL game dialog contains an expandable **Advanced details** section. NBA and NFL quarter scores come from the existing free games feed and use the same score-ingestion checks; browser refreshes read the database every 15 seconds. No extra provider request is needed for quarter scores. Overtime columns appear when reported. Missing cells remain dashes, true zeroes remain zeroes, and incomplete final totals are labeled. Upcoming NBA/NFL quarter scores show a pending message; disabled player stats are labeled unavailable before play too. Spoiler protection omits quarter/player tables and player names until that game's score is revealed.

Quarter scores are available for recent Warriors and 49ers games from the games feed. The WNBA games response contains only game totals, so WNBA dialogs omit the entire Advanced details section. This release does not infer quarters from a final score or scrape another provider. Documentation: [NBA games](https://nba.balldontlie.io/#games), [NFL games](https://nfl.balldontlie.io/#games), [WNBA games](https://wnba.balldontlie.io/#games).

## Player statistics — NBA and NFL enabled

The owner purchased NBA/NFL access and authorized activation. The existing production key returned HTTP 200 with 26 NBA and 63 NFL player rows for recent stored games; all rows passed game/team validation, covered both teams, and fit in one complete page. The existing migration, worker adapters, paginated atomic cache and player tables support these feeds without a new image or migration. The WNBA adapter remains prepared, but its Advanced details interface is hidden until explicitly restored. No player statistics are fabricated. Basketball tables include minutes, points, rebounds, assists, steals, blocks, shooting and turnovers. NFL groups cover passing, rushing, receiving, defense and kicking. Null statistics remain unknown; offensive sacks taken are separate from defensive sacks.

Production uses `PLAYER_STATS_LEAGUES=nba,nfl`; WNBA remains disabled. Examples/defaults keep the value empty for installations without paid access. The worker records enabled leagues in `player_stats_access`, so web never needs the provider key. With no configured leagues, no player-stat job or paid endpoint is called. Detail responses include `playerStats` with an explicit state; schedule/list responses omit player payloads. The UI gives an unavailable message while disabled, pending copy before the first snapshot and a delayed label when retaining data after a failed refresh.

As checked October 22, 2026, NBA/NFL game player statistics require at least each sport's ALL-STAR plan ($9.99/month each under monthly billing). The combined minimum data fee is $19.98/month, separate from AWS/domain charges; the owner's actual bill depends on the purchased tiers and billing term. No WNBA upgrade is required or enabled for this release. Tiers do not apply across sports. See [NBA tiers and stats](https://nba.balldontlie.io/#account-tiers) and [NFL tiers and stats](https://nfl.balldontlie.io/#account-tiers).

For recovery, preserve `PLAYER_STATS_LEAGUES=nba,nfl` in root-managed `production.env` and recreate only the worker with its recorded image. Wait for worker startup to publish access rows, then verify populated NBA/NFL game-detail responses. The key remains in the existing worker-only secret mount. To disable ingestion, set the value empty and recreate the worker; its startup disables public access to cached player rows without deleting them. Local examples stay disabled to avoid running a second ingestion worker against the same quota. WNBA quarter scores remain a separate integration even after player-stat access is purchased.

Optional ingestion checks at most one game per minute under the existing scheduler lock and shared persistent 14-second provider throttle. Pagination is bounded to four pages, validates game/team identity, deduplicates players and publishes only after every page succeeds. Failures retain the previous snapshot and checked time; empty responses cannot erase populated statistics. Entitlement errors back off a league, and rate limits postpone shared access. Live games recheck after a minute, final snapshots after six hours, empty initial responses after ten minutes. Jobs share the schedule ingestion window: the past 45 Pacific calendar days, inclusive, with calendar-date fallback when the start time is unknown. Both job creation and fetching use this shared boundary; this prevents older scheduled results being omitted by a shorter stats cutoff. Live games have priority. Enabling paid feeds adds requests; review score-check timing when doing so.
